# THMrecipes

A simple recipe web app built with **Java (Vert.x)** for the backend and **HTML/CSS/JavaScript** for the frontend.  
Developed as a university project at THM in 2024.

## Features
- Login or register
- delete or modify account (name , email , password)
- View and add recipes (image , description and instructions)
- delete or modify own recipies.
- view and add comments and star reviews 
- own recipes ,comments and reviews appear on user profile.
- add recipes to wishlist
- dark mode

## 🛠️ Setup

### Prerequisites
- Java 11+  
- Maven 

### Run
```bash
git clone https://github.com/ilias314/THMrecipes.git
cd THMrecipes
./mvnw clean compile exec:java
Then open: http://localhost:8080
